Enum values and booleans can be written bare (button primary lg, checkbox checked, toggle off); anything else is key=value. Lists use commas, and items can contain spaces: [All notes, Pinned]. Quote an item that contains a comma: ["$1,200", "Smith, J"]. Objects are {key=value key=value}.
