# Tasks

Write one wireframe per task.

## n1-checkout
A phone checkout screen: an order summary with two items and a total, a promo code field, a card number field, and a full-width Pay button. Add two notes: the promo code field accepts one code per order, and the Pay button stays disabled until the card number is valid.

## n2-signup-flow
A sign-up flow on three phone screens (create account, verify email with a 6-digit code input, welcome), with arrows between the screens. Add a note on the code input saying the code expires after 10 minutes, and a note about the whole board saying all copy is a draft.

## n3-settings-decisions
A desktop project settings page: a sidebar with sections, a form with the project name and visibility (public or private), and a danger zone with a Delete project button. Annotate the key design decisions with notes.

## n4-profile-tooltip
A phone profile screen with an avatar, the user's name and email, and an Edit profile button. The Edit profile button shows a tooltip "Opens the profile editor". Add a note for the developers that avatar uploads are limited to 5 MB.

## n5-responsive-board-note
Show the same notes list on a phone and on desktop side by side, with a sticky note on the board explaining what changes between them.

## n6-onboarding-screen-note
Three phone onboarding screens: welcome, choose interests (selectable options and a Continue button), and enable notifications. Add a note about the notifications screen as a whole: it is skipped when the user already granted permission. Also note that Continue on the interests screen stays disabled until at least 3 interests are selected.

## n7-orders-table
A desktop orders page with a search field, an Export button and a table of orders (order, customer, status, total). Add notes: the status column is sortable, and Export downloads only the filtered rows.
